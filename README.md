# AI Quiz & Question Generator (Python + Streamlit + Gemini)

## Setup
1. Python 3.10+ install karo
2. Folder kholo, terminal mein:
   pip install -r requirements.txt
3. `.env.example` ka naam `.env` karo aur Gemini API key paste karo
   (free key: https://aistudio.google.com)
4. Run:
   streamlit run app.py

## Features
- Koi bhi topic, 5-50 questions, MCQ / Short / Long, difficulty
- Numbered questions, checkbox se selection (Select All / Clear / First N)
- Selected questions ka PDF download (optional answer key)
- Attempt Quiz tab with automatic score
